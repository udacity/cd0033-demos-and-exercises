# Data Governance Demos & Exercises (cd0033)

This repository contains the instructor demos, learner starter workspaces, and reference solutions for all nine modules of **Data Governance (cd0033)**:

- **MP1_governance-models** — Choose a Governance Model for Trailhead Provisions
- **MP2_metadata-governance** — Audit & Remediate Catalog Metadata in AWS Glue
- **MP3_data-contracts** — Extend & Validate a Data Contract
- **MP4_data-quality** — Interpret Quality Results & Plan Remediation
- **MP5_master-data** — Adjudicate Master-Data Matches & Set Survivorship
- **MP6_lineage-monitoring** — Trace Lineage & Specify Monitoring
- **MP7_access-control** — Configure Governed Access in AWS Lake Formation
- **MP8_regulatory-reporting** — Verify Cross-Domain Reporting Traceability
- **MP9_governance-operations** — Run Governance as an Operation
